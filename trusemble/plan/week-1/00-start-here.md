# Week 1: learn before you build

**Goal for the week:** by Friday you know who you are building for, what they actually need, and that you can get the real data.

**You are done when:**
- 8 to 10 short calls are finished and written up (5 funders, 5 communities).
- You have written access to the live site, the data sources and the accounts you need.
- You have looked at one real sample from each key data source.
- You have picked the first county and the first funder to serve.
- You can say the three sentences (see file 04) without reading them.

## Day by day

| Day | Do this | Done when |

| **Tue** | First 3 calls. Write notes right after each one using the note sheet in file 01. | 3 notes written within an hour of each call |

## Invitation message (copy and edit)

> Hi [name], I'm working on a free tool that shows where wildfire money has gone and which ready projects still need funding. I'd love 20 minutes to hear how you do this today. I'm not selling anything and there's nothing to prepare. Could we talk on [two options]?

## Rules for the calls
- Ask about **what they do today**, not whether they'd like your idea.
- Let silence sit. The best answers come after a pause.
- Never show a screen in the first 15 minutes.
- Write down their exact words. Quotes beat summaries.
- Thank them and ask: "Who else should I talk to?"
